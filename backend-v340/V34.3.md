# V34.3 laboratory
Local standalone responsive panel served on 127.0.0.1:15002 via node functions/admin-panel-server.mjs with existing demo emulator environment. Start emulators first; use only synthetic emulator bearer tokens, held in memory, not browser storage. No hosting deploy or production frontend changes. Admin/Owner can read account usage by UID and paginated list (25 rows); indicators are page totals for current UTC minute/day/month, not lifetime or global aggregates. Admin may alter ordinary accounts only; Owner may alter operator limits. Version compare-and-set and immutable audit create are atomic; quotas consumed before provider in same transaction that reads override. Audit metadata only, no financial or document content. No audit-list UI yet; audit records available in emulator collection. No global spend cap, retention policy, real provider, App Check, browser E2E, real account data or deployment. Limits 1..10000 ordered minute <= day <= month, defaults unchanged. No V35.0.
